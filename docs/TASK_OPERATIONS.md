# 任务复制、导出与清理

任务列表的操作菜单与扫描结果页提供相同功能，所有操作沿用管理员认证。

## 复制任务

先读取原任务的完整输入，不能拿仅保留前两条目标的列表摘要来复制。创建页预填目标、端口/HTTP模式和HTTP四项开关，用户可修改后创建。新任务使用当前规则、独立执行与预算；原任务和历史结果保持原样。PoC默认关闭，需要再次显式开启。历史任务没有新开关时采用当前创建页默认值并提示核对，不伪称复现历史执行。

## CSV / JSON 导出

可以选择目标汇总、开放端口与服务、HTTP端点与指纹或已有PoC检查结果。导出整个任务，不跟随当前页码、搜索词或筛选；运行中的任务也可导出，并保存快照时点。

- JSON包含run元信息、全部目标质量`target_quality`及所选`items`。目标类型的数据在`target_quality`内，`items`为空。
- CSV以`record_type=target_quality/result`区分两类行，常用字段单独成列，其余结构化摘要位于`details_json`，任务元信息位于`run_json`。
- 导出完整不等于扫描完整：端口覆盖、partial、失败及受限识别状态保留；没有发现端口的目标仍在质量记录中。
- 结果导出不包含原始HTTP报文、PNG或凭据；报文和图片仍在原详情查看。它不是完整证据备份。

后端复用列表查询和接受版本/独立阳性凭证规则，在单个只读快照中分批读取，内存不随结果总数线性堆积。先生成权限受限的临时文件再发送附件；中途查询或写入失败返回错误并清理文件。CSV处理公式前缀，URL凭据与摘要内敏感字段剔除。

## 手动清理

仅已结束任务显示可用删除操作，确认后永久删除任务、观测、截图及其私有执行记录。暂停、排队、执行中、有效租约/许可或尚未确认停止的额度均阻止删除。不能把租约过期当作Worker已停的证据。

删除事务使用该run及task行锁，保留共享规则、指纹包和其他任务。没有使用全局调度锁包住级联删除；大型清理仍会消耗数据库IO，因此不宣称零性能成本。删除后清空相关页面缓存，已经删除的任务不会因刷新失败重新出现。

## 数据存储

Workers的数据存储页展示数据库总大小、主要表的估算行数/分配体量与统计时点。总体大小读取最多每分钟一次；表数据来自PostgreSQL统计信息，不扫描全部业务行。磁盘剩余容量无法从当前连接可靠取得，明确显示未知。

当前只提供显式清理和容量可见性，没有自动过期删除、自动PG压力熔断、分区或对象存储归档。数据库删除可释放内部可复用空间，不保证立即把文件空间还给操作系统。

必要检查和真实界面/HTTP证据见[验证记录](validation/task-tools-20261022/validation-log.md)。
