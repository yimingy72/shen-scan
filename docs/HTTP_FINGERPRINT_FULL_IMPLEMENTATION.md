# HTTP 指纹执行重构

状态：核心实现与本地工具链验证已完成；生产发布状态以交付记录为准。本文记录经“构建扫描器方案”会话复核后的实现边界。

## 执行流程

```text
HTTP 入口（URL、connect IP、Host、SNI）
  → 完整 httpx Runner：页面、重定向、TLS、图标、基础元信息
  → WappalyzerGo：所选官方规则对采集证据进行匹配
  → fingers：Fingers / FingerprintHub / EHole / Goby / favicon 被动匹配
  → 原生主动规则：复用已取得响应，执行尚未完成的请求和 matcher
  → 产品归一、证据与覆盖状态
  → 已显式开启时，按产品匹配派生 PoC
```

任务开启主动识别时，没有被动命中的站点同样进入主动指纹发现；已有产品只改变执行优先级。不同引擎的重复请求允许复用响应，但规则的 AND/OR、变量链和 favicon 条件保持原语义。

## 模块与边界

| 模块 | 实现责任 |
|---|---|
| web-probe-worker | 官方 `runner.New → RunEnumeration → Close`；每入口独立 Runner；在官方 Transport 外接许可和证据记录 |
| fingerprint-worker | 加载完整公开 HTTP 资源；原生被动与主动 matcher；逐完整 finger/template 执行结局 |
| Agent | 固定许可服务、进程生命周期、任务取消、结果与进度提交；保持输入连接身份 |
| Control | attempt fence、不可变规则引用、累计请求预算、续段、最终状态 |
| 规则库页面 | 一个 HTTP 目录展示来源、执行方式、装载状态与原文；保留端口和 PoC 分类 |

不引入新调度框架，不把每个规则转换成一个数据库任务。Masscan、Nmap 和 TCP 1–65535 覆盖口径不变。

## 规则退役与完整性

- 精确退役平台内置 151 条普通 native HTTP 指纹及 6 条补采规则，共 157 条。
- 删除接口已有持久软删除；初始化跳过删除记录。新版本移除种子并按原 ID、来源、种类和内置标记补退役迁移。
- 保留历史任务冻结快照、自定义规则、端口规则、PoC 和 fingers 自身 native 引擎。
- 完整 HTTP 包保留上游原始字节和来源，不再因 favicon、title 或主动请求而静默剔除。
- 装载数量、规则语义支持和真实执行覆盖分别核对。别名不是指纹，服务/套接字规则不计入 HTTP 数量。
- WappalyzerGo 的 JS/DOM 条件依赖浏览器证据；页面 HTML 或开启 headless 都不能自动证明这类条件已执行。能力缺口必须显式呈现。

## 协议与恢复

新路径使用 `web-full-v2`，只派给声明相应能力的 Worker。旧快照保持旧范围执行，未知 profile 不静默回落。

JSONL 仅传身份、截止时间、授权、规则/证据引用及结构化结果。Context、Transport 和回调为进程内对象。许可服务由 Agent 配置，规则不能改变地址。

入口固定规则包和选择范围；执行单元身份包含引擎、来源、原 ID/路径与内容摘要。进度变化不能改变范围摘要。完成单位为完整 finger/template；中断的有状态模板有界重启，已接受的完成单位跨 attempt 保留。

入口预算以每段最多 1,024 预留并在许可事务中记录累计授权；失联未结算的部分不恢复额度。重试、重定向、favicon 和主动请求分别领取；命中缓存不再领取。共享速率与累计预算独立核算。总截止和总预算跨续段不重置。

工作终结与完整覆盖分开：预算、读体截断、缺能力、失败或重试耗尽可以结束工作，但不能标记为完整未命中。入口终态与续段安排在现有事务和完成凭证内处理。

## 必要验证

1. 157 条精确删除、重启/再次初始化不回灌，历史快照及非目标规则保留。
2. 完整资源数量与原文对账；title、favicon 与页面组合条件、多产品同 hash 不丢失。
3. 未知站点主动发现及已有产品后继续发现其他产品；请求缓存身份正确。
4. 固定 IP/Host/SNI、逐跳请求、取消、许可与首次读体限长。
5. 已接受进度后换 attempt；发出许可但未结算失联；无重复完成、无预算重置、无假完整覆盖。
6. 本地完整工具链跑通后再发布；报告附真实截图与完整自建目标 HTTP 报文。

部署与验证完成前，不将本文件的设计约定当作已通过结果。

## 已验证的规则质量边界

公开 Goby 数据的裸 `rdp` 特征会命中 `WordPress` 子串。保留原规则和命中，仅当没有独立词 `rdp` 且移除这一正向证据后原逻辑不再成立时标记为候选。候选在页面和证据中保留，不触发产品 PoC；获得独立确认后可提升。该处理只覆盖已证明的误报，不宣称全库准确率。

Wapp JS/DOM 已接入独立可选的 Chrome 子任务，与首页截图共享页面加载；未选择、无法求值和实际未命中分别记录。Wapp 同步与实际匹配支持分别展示。任务选项、安装和截图边界见 [HTTP 浏览器能力](HTTP_BROWSER.md)。
